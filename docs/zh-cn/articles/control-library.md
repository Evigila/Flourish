# 控件库

Flourish 提供显式 WPF 控件，用于统一页面、Shell 区域、对话框和窗口的主题与交互。它不替换 WPF 基础控件样式；通过 `http://schemas.arkheide.system/flourish` XAML 命名空间按需使用。

设计指南、默认值和示例见[控件文档](../controls/index.md)：

- [PageBody](../controls/page-body.md)
- [HeaderChunk 与 Chunk](../controls/chunk.md)
- [Document](../controls/document.md)
- [CodeSpace](../controls/code-space.md)
- [Presenter](../controls/presenter.md)
- [Card 家族](../controls/card.md)
- [OutputCard](../controls/output-card.md)
- [Button 家族](../controls/button.md)
- [DataGrid](../controls/data-grid.md)、[Overlay](../controls/overlay.md) 和 [ScrollViewer](../controls/scroll-viewer.md)

另见 [Controls API](xref:ArkheideSystem.Flourish.Controls) 和[设计理念](../conception/index.md)。

# Control library

Flourish controls provide consistent WPF layout, typography, theming, and interaction without replacing base-control styles. Opt in through `http://schemas.arkheide.system/flourish`.

Design guidance, properties, defaults, and examples live in the dedicated [Controls documentation](../controls/index.md):

- [PageBody](../controls/page-body.md): page root
- [HeaderChunk and Chunk](../controls/chunk.md): page sections
- [Document](../controls/document.md): prose
- [Presenter](../controls/presenter.md): rich presentation
- [Card family](../controls/card.md): focused surfaces
- [OutputCard](../controls/output-card.md): output history
- [Button family](../controls/button.md): actions
- [DataGrid](../controls/data-grid.md), [Overlay](../controls/overlay.md), and [ScrollViewer](../controls/scroll-viewer.md): specialized behavior

See the [Controls API](xref:ArkheideSystem.Flourish.Controls) and [design principles](../conception/index.md).

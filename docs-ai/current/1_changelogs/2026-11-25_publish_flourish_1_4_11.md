# Promote Flourish 1.4.11 to a stable package release

The 1.4.11 package set promotes the Blazor updates exercised by Colligere with 1.4.11-preview.8. It includes docked page titles and actions with restoration of the shell brand, refined light navigation and table surfaces, unified dropdown selection and menu spacing, and responsive header and presentation layout. The Gallery retains these changes in its localized 1.4.11 history and advances its development entry to 1.4.12-preview.

The package version, six NuGet package identities, their internal dependencies, 119 Noto fonts and license notices, and the required static assets passed local verification. Essential Culture remains at 1.4.0. The `v1.4.11` tag carries the approved release notes and starts the existing GitHub Actions trusted publishing workflow.

Framework passed 544 checks, Gallery passed 9,513 checks, and the Node runner passed 354 tests. The two legacy header assertions now check independent slots, shared brand and docked title sizing, and bottom elevation. Browser acceptance remains manual.

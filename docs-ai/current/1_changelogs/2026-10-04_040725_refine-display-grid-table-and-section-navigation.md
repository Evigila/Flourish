# Refine reusable display, grid, table and page navigation controls

## Request and scope

Implement the seven Gallery/library refinements: generic dotted boards and icon-only copy feedback; shared rectangular/square grid cells; square category directories; text-scoped table sorting and 10/20/50/100 page sizing; transparent idle dropdown options; right-gutter section indicators; and full-page document scroll ownership. Changes belong to the general Blazor libraries and Gallery. No Colligere business pages or resources were added or changed. No dependency was added and no Git commit was created.

## Implemented behavior

- DisplayBoard now exposes independent Dotted=true and Centered=true options, optional CopyText and arbitrary ChildContent. DisplayBoardVariant was removed. Gallery composes code using a non-dotted, start-aligned board with CodeBlock. The Elevated icon-only copy action has an accessible label, sits at the top right with a selector that outranks Button positioning, copies the complete string and changes content_copy to check for 1600 ms. New copies, changed text and disposal cancel stale feedback.
- UniformGrid defaults to Rectangle cells and automatic CSS tracks. Square applies to cells, not the whole container. Nullable Rows/Columns and optional NarrowColumns allow explicit arrangements; Rows-only fills columns without dropping excess content. UniformGridItem and UniformGridButton share one internal content renderer and skin. Title uses the 34px H1 role; descriptions and optional custom content use 17px body text. Native actions, links, Busy/Disabled and button type are preserved. Busy spinners occupy a corner instead of adding height to the centered content. Simple legacy Gallery action labels were migrated to Title.
- All eight category directories use Square UniformGrid and navigable UniformGridButton cells. UniformGridItem and SectionNavigator were registered with independent guides and explicit third-level navigation. There are 78 component guides and executable sample sources.
- DataTable defaults to ten records per page. Synchronized top/bottom page-size selectors offer 10/20/50/100 and retain a custom consumer value. Changes reset page one and raise PageSizeChanged, supporting @bind-PageSize without overwriting local selection on an unrelated rerender. Sort headers use Quiet Button semantics with an inner label border; measuring accounts for its padding. The final visible data column remains exempt from the ordinary automatic width cap.
- Display options share ActionMenu's popup/item rules. Selected rows keep a transparent idle surface; pointer hover or visible keyboard focus highlights the option. Clicking a checkbox does not retain a filled row merely because it still has pointer-origin focus.
- SectionNavigator is a generic component included by ApplicationShell. It discovers only page-level H2 sections, excluding nested examples and modal headings. Explicit Items preserve SSR fragment links. The fixed right-gutter indicator does not reduce the content track. Hover/focus shows the title; current-section dots grow and gain an accent outline. Clicking scrolls only the associated content, accounts for sticky heading compaction, respects reduced motion and cancels pending alignment on user interruption or disposal.
- ApplicationLayout defaults OwnsDocument=true; the low-level ApplicationShell defaults false. A full-page shell marker activates Framework CSS that bounds html/body and fixes the shell to the viewport. The content scroll region remains the page scroll owner. Embedded Gallery layouts explicitly opt out. The previous Busy mitigation did not address this independent document scroll path; its historical report is retained, with a new document-scroll report explaining this correction.

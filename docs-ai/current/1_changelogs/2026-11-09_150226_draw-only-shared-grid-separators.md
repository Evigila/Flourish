# Draw only real shared grid separators

2026-11-09 15:02:26 · America/Sao_Paulo · UTC−03:00.

Follow-up to [the inner-shadow fix](2026-11-09_140940_remove-inner-uniform-grid-shadows.md): the earlier per-cell inline-end/block-end borders also drew visible right and bottom exterior lines. Simply removing the last DOM child's borders would fail for automatic columns, column-first Rows layouts, breakpoint changes and incomplete grids.

The zero gap, transparent group, opaque occupied cells and existing outer group filter remain. Cell boundaries keep their one-pixel transparent geometry, including hover/active/unavailable states, so line changes do not resize or reflow content. A Framework-owned absolute pointer-transparent group pseudo-element paints only measured shared segments. Only rendered direct .f-uniform-cell children participate; standalone UniformGridButton and non-cell children such as Avatar never acquire these separators.

The new patterns/uniform-grid-dividers.js intersects physical rectangle edges and merges collinear segments. Actual intersection length covers capped/Information mixtures and cells spanning wider tracks without drawing uncovered portions. Geometry is independent of row-major/column-major DOM order or RTL order. Coordinates are local CSS pixels normalized by computed layout extents versus measured bounds, supporting fractional tracks and axis-aligned scale transforms without background-position percentage drift. It does not change Blazor DOM or grid placement.

Resize/content/visibility changes recompute the paint. Relevant style/class mutations are scoped to the group, ancestors or descendants; owned style snapshots suppress feedback, unchanged paint is not rewritten, and unrelated PageHeading style changes do not schedule work. Hidden groups release paint, removed groups release observations, and final removal releases document listeners, observers and pending frames. Gallery now explicitly loads the existing input-behaviors module through its asset collection; that entry discovers the grid module for direct navigation and SSR. The module and its Node regression are registered in ReleaseSettings.

Design uses the existing border color. Forced-colors sets CanvasText on the group, where custom-property images resolve, and disables forced adjustment only on the decorative pseudo-element. Keyboard focus and all original control semantics remain native. Before enhancement, external boundaries remain transparent rather than briefly exposing the retired exterior outline.

Coverage includes incomplete row/column layouts, partial overlaps and wider cells, hidden/non-cell children, fractional/scale geometry, narrow relayout, stable observer writes, teardown and startup assets.

# Add controlled server data to DataTable

Recorded 2026-10-29 19:26:26 America/Sao_Paulo (UTC-03:00). This advances the reusable table contract required by Colligere Liquidity's bounded company and bank-account directories. It retains the preceding SaveChangesBar and Gallery settings work.

`DataTable<TItem>` now has an opt-in `ServerData` mode with `CurrentPage`, `TotalCount`, `SortColumnKey`, `SortDirection` and one `QueryChanged` callback. The Abstract package owns `TableQueryRequest(Page, PageSize, SortColumnKey, SortDirection, SearchColumnKey, SearchQuery)`. Local mode remains the default. Server mode renders exactly the supplied page in the supplied order; it does not locally filter, sort, page or restore stored sort preferences. The total and accepted current page come from the host. Empty pages show a zero range.

Page, page-size, sort and remote-search interactions submit a complete query. Sort/search/page-size changes request page one. The accepted controls are not advanced optimistically; the host supplies the new page and its metadata after success, or retains the accepted state and its error after failure. Loading and an executing request suppress duplicate requests. Columns without backend sort support must declare `Sortable=false`; searchable server tables require `SearchMode=Remote`. Progressive rendering and buffered bulk editing are rejected in this mode. Native row actions, record opening, column visibility and layout remain the existing Flourish features.

The host remains responsible for authorization, tenant/company scope, query validation, stable server ordering, count consistency, cancellation, late-response rejection and page error presentation. This contract does not fetch data, create an unbounded client cache, claim whole-dataset filtering for a single page, or certify backend authority. The Liquidity consumer handles those responsibilities in its own application and API layers.

The six-package manifest, external dependencies, SDK, fonts and static resources are unchanged; both Abstract and Framework assemblies change.

# Reuse the original heading controls in the compact bar

2026-11-09 14:25:42 · America/Sao_Paulo · UTC−03:00.

The text-only floating heading now restores the original parent action on the left and the original Actions content on the right. Each control and RenderFragment still renders once. PageHeading adds normal-flow slot and anchor wrappers, while retaining the exact f-heading-actions class on its actual action container. It does not reparent, clone or recreate Blazor DOM, add duplicate IDs or h1 elements, or create extra keyboard stops.

Before pinning, the controller measures the natural slots and reserves their widths/heights. The existing anchors use CSS fixed positioning above those retained slots. The parent keeps its standard Underline control and accessible name; only its icon appears in the 48px compact target. A decorative, inert overlay contains the title and empty measured spaces. On narrow regions the action space wraps to a second row. Explicit Compact and DocumentFlow retain their earlier behavior.

Resize and asynchronous control-content changes remeasure the original layout synchronously and then restore its fixed positions. Stable scrolling reuses those measurements and avoids clearing coordinates or rewriting unchanged values. The controller remembers the pre-measurement pinned state: a focused control whose natural slot is still outside the visible region stays pinned until its natural slot returns or focus leaves. Cleanup releases reserved dimensions and fixed styles. It never calls focus or changes business visibility.

Live anchors deliberately have no translation, opacity animation or overflow clipping, preserving visible focus, native selectors and unenhanced inline-menu behavior. The decorative title panel retains its existing vertical motion. The shared controls module records positioned popup states weakly and provides refreshAnchoredPopups for explicit post-layout relocation. It repositions only open popups anchored inside the affected heading, without reopening them or changing focus. This covers a trigger moved after the scroll event was already handled.

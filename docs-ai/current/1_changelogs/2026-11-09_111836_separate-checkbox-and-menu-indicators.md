# Separate standalone checkboxes from embedded selection marks

2026-11-09 11:18:36 · America/Sao_Paulo · UTC−03:00.

The previous styles reused 28px boxed selection geometry for standalone fields and popup indicators. Standalone CheckBox, StandaloneCheckBox and the native form-check boundary now follow the standard control height, 48px by default. Popup choices retain their existing 28px slot, move it to the right and draw only a selected check, with no marker border or fill. Option hover/focus/selection paint remains owned by the row.

The internal static SelectionIndicator offers direct Render/Input fragments without extra component instances or a public API. MultiSelectBox retains its native checkbox, stable selection key, fixed/disabled flags and existing controller. ReferenceDropdown includes the same slot in its hidden intrinsic-width rows and visible choices; its marker is decorative. Enhanced native selects retain menuitemradio/aria-checked and the original native form carrier. The native picker uses its own checkmark pseudo-element. SearchAutocomplete's active suggestion is not a committed selection, so it receives no new check. Forced-color marks use CanvasText.

Release solution build passed with zero warnings/errors. Framework passed 535 checks, Gallery 9298, actual CSS cascade 35, control DOM 88, table geometry 8 and CSS bundle 21. The reference-dropdown test helper was updated to read the label span rather than treating all inner markup as plain text; selection, filtering and ordering assertions remain. The built framework.css contains the new marker styles. CssBundle.targets deliberately bundles internal styles into framework.css and excludes raw internal CSS assets, so ReleaseSettings continues checking the existing bundle rather than adding a nonexistent standalone package asset. No package was created.
